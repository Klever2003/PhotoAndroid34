Features and Usage Guide
Album Management
Creating Albums

From the home screen, enter an album name in the text field at the bottom
Tap the "Create Album" button
The new album will appear in the list

Opening Albums

Tap on any album in the list to open it and view its contents

Renaming Albums

Long-press on an album in the list
Select "Rename" from the popup menu
Enter a new name in the dialog
Tap "OK" to confirm

Deleting Albums

Long-press on an album in the list
Select "Delete" from the popup menu
Confirm deletion in the dialog

Photo Management
Adding Photos

Open an album
Tap the "Add Photo" button
Select an image from your device's gallery
The photo will be added to the current album

Removing Photos

Open an album
Tap on a photo to select it
Tap the "Remove Photo" button
Confirm removal in the dialog

Moving Photos Between Albums

Open an album
Tap on a photo to select it
Tap the "Move Photo" button
Select the destination album from the dialog

Photo Tagging
Adding Tags

Open a photo in full view
Tap the "Tag" button
Select "Add Tag"
Choose a tag type (PERSON or LOCATION)
Enter the tag value
Tap "OK" to add the tag

Removing Tags

Open a photo in full view
Tap the "Tag" button
Select "Remove Tag"
Choose the tag you want to remove from the list
The tag will be removed from the photo

Search Functionality
Searching with a Single Tag

From the home screen, tap the "Search" button
Ensure "Single Tag" is selected
Choose the tag type (PERSON or LOCATION)
Start typing a tag value - the app will show auto-complete suggestions
Tap the "Search" button to find matching photos

Conjunction (AND) Search

From the home screen, tap the "Search" button
Select "AND" option
Configure first tag (type and value)
Configure second tag (type and value)
Tap the "Search" button to find photos that match BOTH criteria

Disjunction (OR) Search

From the home screen, tap the "Search" button
Select "OR" option
Configure first tag (type and value)
Configure second tag (type and value)
Tap the "Search" button to find photos that match EITHER criteria

Viewing Search Results

After performing a search, tap on any photo in the results
The photo will open in full view
You can navigate through search results using the previous and next buttons
